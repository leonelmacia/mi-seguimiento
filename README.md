# MI Seguimiento

Aplicación personal para registrar alimentación, calorías, proteínas, carbohidratos y grasas.

## Objetivo

Crear una base simple y móvil para registrar comidas rápidamente y evolucionarla después hacia una aplicación Android.

## Primera etapa

- Catálogo de alimentos
- Registro diario
- Cálculo de calorías y macronutrientes
- Alimentos rápidos y favoritos
- Historial diario
- Diseño preparado para celular

## Próximos pasos

1. Agregar la base inicial de alimentos.
2. Crear el registro de comidas del día.
3. Incorporar objetivos diarios.
4. Preparar persistencia de datos y cuentas de usuario.
